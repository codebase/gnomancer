Install gnomancer

gnomancer is a command-line program today. That means a few minutes in the Terminal once, after which running it is one line. A point-and-click app is on the roadmap. Nothing here creates an account or uploads anything.

macOS

  1. Open Terminal (press ⌘ Space, type Terminal, press Enter).
  2. If you have never used Homebrew, install it from brew.sh (one command on that page), then install the three prerequisites: 
    brew install git python@3.12 openjdk
  3. Install gnomancer: 
    curl -fsSL https://gnomancer.com/install.sh | bash
    This puts everything in a folder called gnomancer in your home directory and downloads the open-source tools and reference files it uses (about 250 MB, once). You can read the script before running it.

Linux

  1. Install the prerequisites with your package manager. Debian or Ubuntu: 
    sudo apt install git python3 python3-venv default-jre
    Fedora: sudo dnf install git python3 java-21-openjdk
  2. Then: 
    curl -fsSL https://gnomancer.com/install.sh | bash

Windows

gnomancer runs on Windows through the Windows Subsystem for Linux, which Microsoft ships with Windows 10 and 11. It takes one extra step the first time.

  1. Open PowerShell as administrator and run wsl --install. Restart when asked and set a username and password for Ubuntu when it opens.
  2. In the Ubuntu window, install the prerequisites and gnomancer: 
    sudo apt update && sudo apt install -y git python3 python3-venv default-jre
curl -fsSL https://gnomancer.com/install.sh | bash
  3. Your Windows files are visible inside Ubuntu under /mnt/c/, so a file in your Downloads folder is at /mnt/c/Users/YourName/Downloads/.
A native Windows installer is on the roadmap. If you are comfortable with Python on Windows already, pip install git+https://github.com/codebase/gnomancer works too, without the Java-based haplogroup and PharmCAT steps.

Run it

First download your raw data file from your testing company. Then:

gnomancer ~/Downloads/dna-data-2026-11-02.zip

It takes about a minute. The report appears in a new folder next to your file; open REPORT.html in any browser. Add --ancestry for a population estimate (slower the first time, it downloads reference models) and --summary summary.md to embed a narrative written by your AI assistant (the run writes a ready-made prompt for it as summary-prompt.md).

If gnomancer is not found, use the full path: ~/gnomancer/.venv/bin/gnomancer.

Trouble?

  • "python3: command not found": install Python 3.10 or newer (macOS: brew install python@3.12).
  • Java warnings: the mitochondrial haplogroup and PharmCAT sections need Java 11 or newer. Everything else runs without it.
  • "Could not parse any SNPs": the file is probably not a raw-data export. Check which file to download; a PDF or the company's report file will not work.
  • Anything else: open an issue on GitHub (no account needed to read existing ones) and include the first 20 lines of your file's header, never the genotype lines.
