Install gnomancer

gnomancer is a command-line program. That means a few minutes in the Terminal once, after which running it is one line. If you use an AI assistant such as Claude, it can do all of this for you through the MCP server. Nothing here creates an account or uploads anything.

macOS

  1. Open Terminal (press ⌘ Space, type Terminal, press Enter).
  2. Paste this one line and press Enter: 
    curl -fsSL https://gnomancer.com/install.sh | bash
    It installs the gnomancer package from PyPI into a private folder (~/.gnomancer) and downloads the open-source tools and reference files it uses (about 250 MB, once). You can read the script before running it. If no usable Python is found it tells you the quickest fix (install uv and re-run, or the python.org installer).
  3. For the mitochondrial haplogroup and PharmCAT steps, install Java 17 or newer once: brew install openjdk (needs Homebrew). Everything else works without it.
Also available: brew install codebase/tap/gnomancer (brings Python and Java with it) and, if you already use Python tooling, pipx install gnomancer. The first run downloads the tools automatically.

Linux

  1. Install the prerequisites with your package manager. Debian or Ubuntu: 
    sudo apt install python3 python3-venv openjdk-17-jre
    Fedora: sudo dnf install python3 java-21-openjdk. Java is only needed for the mitochondrial haplogroup and PharmCAT steps.
  2. Then: 
    curl -fsSL https://gnomancer.com/install.sh | bash

Windows

gnomancer runs on Windows through the Windows Subsystem for Linux, which Microsoft ships with Windows 10 and 11. It takes one extra step the first time.

  1. Open PowerShell as administrator and run wsl --install. Restart when asked and set a username and password for Ubuntu when it opens.
  2. In the Ubuntu window, install the prerequisites and gnomancer: 
    sudo apt update && sudo apt install -y python3 python3-venv openjdk-17-jre
curl -fsSL https://gnomancer.com/install.sh | bash
  3. Your Windows files are visible inside Ubuntu under /mnt/c/, so a file in your Downloads folder is at /mnt/c/Users/YourName/Downloads/.
If you are comfortable with Python on Windows already, pip install gnomancer works too (the first run downloads the tools); install a Java 17+ runtime for the mitochondrial haplogroup and PharmCAT steps.

Run it

First download your raw data file from your testing company. Then:

gnomancer ~/Downloads/dna-data-2026-11-02.zip

It takes one to three minutes. The report appears in a new folder next to your file; open REPORT.html in any browser. Add --ancestry for a population estimate (slower the first time, it downloads reference models) and --summary summary.md to embed a narrative written by your AI assistant (the run writes a ready-made prompt for it as summary-prompt.md).

If gnomancer is not found, use the full path: ~/.gnomancer/venv/bin/gnomancer.

Trouble?

  • "No working Python 3.10+ found": install uv and re-run the installer (it fetches a standalone Python), or use the python.org installer.
  • Java warnings: the mitochondrial haplogroup and PharmCAT sections need Java 17 or newer. Everything else runs without it.
  • "Could not parse any SNPs": the file is probably not a raw-data export. Check which file to download; a PDF or the company's report file will not work.
  • Anything else: ask in the Discord (#install-help) or open an issue on GitHub. Include the first 20 lines of your file's header, never the genotype lines.
