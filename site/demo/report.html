Glossary

Terms used in this reportOpen for one-line definitions.
Haplogroup
A branch of the human family tree defined by shared mutations on the Y chromosome (paternal line) or mitochondrial DNA (maternal line). It describes one ancestral line, not overall ancestry.
Site / marker / SNP
One position in the genome where people differ. A consumer chip types a fixed list of around 600,000 of them; this report calls them sites.
rsID
The public catalogue number for a site, e.g. rs4988235. Useful for looking a site up in SNPedia or ClinVar.
Genotype
The two letters you carry at a site, one from each parent (one letter on X or Y in males).
Effect allele
The version of a site that the published association is about. The badge counts how many copies you carry: 0, 1 or 2.
Heterozygous / homozygous / hemizygous
Two different letters at a site / two of the same / only one copy present (X and Y in males, and mitochondrial DNA).
Carrier
One copy of a variant for a recessive condition. Carriers are usually unaffected; the result matters mainly for children, if the other parent carries one too.
Odds ratio (e.g. ~2x)
How much a variant multiplies the odds of a condition in population studies. It is relative, not absolute: 2x of a 1% risk is 2%.
Run of homozygosity
A long stretch where both chromosome copies match, which happens when parents share recent ancestors.
Diplotype / star allele
A pharmacogenomics term for the pair of gene versions you carry, named *1, *2, *3 and so on; the pair determines a metabolizer phenotype.
Phenotype (metabolizer)
What the diplotype predicts: normal, intermediate, poor or rapid metabolism of certain drugs.
ClinVar
The public NIH archive of variants and their clinical classifications, with a review status from zero to four stars.
GRCh37 / build 37
The version of the human reference genome that consumer vendors report positions against; files on build 38 are remapped.
1000 Genomes
A public reference set of about 2,500 genomes from 26 populations; the source of the "how common" percentages.

What this file cannot tell you

  • Rare pathogenic variants. The chip targets common variation; genes like BRCA1/2 and CFTR are covered at a handful of sites only.
  • Copy-number genes such as CYP2D6, and full HLA types beyond tag SNPs.
  • Admixture percentages at the resolution of the vendor's own report, which uses a proprietary reference panel.
  • Anything at sites the vendor did not type. PharmCAT assumes the reference allele at untyped positions, so a "complete" diplotype can still miss a rare allele.
  • For a male sample, X-chromosome sites have one copy (hemizygous), so "carrier" and "homozygous" do not apply there in the usual sense.
  • "How common" uses the European reference population unless --ancestry placed you in another 1000 Genomes group; a different reference changes those percentages, not your genotype.
